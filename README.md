# WorkConnect – Local Job & Skill Matching Portal

WorkConnect is a web-based platform designed to connect local daily-wage workers with employers such as households, hotels, shopping marts, and contractors.

The platform helps workers discover nearby job opportunities and allows employers to post jobs and manage applications easily.

## 🎯 Project Objective

The main objective of WorkConnect is to make local employment opportunities more accessible by providing a simple platform where workers can find jobs based on their skills and location, while employers can find suitable workers.

## ✨ Features

### 👷 Worker Module
- Worker Registration and Login
- Worker Dashboard
- Profile Management
- Browse Available Jobs
- Search Jobs by Title and Location
- Filter Jobs by Category
- View Job Details
- Apply for Jobs
- View My Applications
- Track Application Status
- Receive Application Notifications
- Unread Notification Counter

### 🏢 Employer Module
- Employer Registration and Login
- Employer Dashboard
- Business Profile Management
- Post New Jobs
- View Posted Jobs
- Edit and Delete Jobs
- Close and Reopen Jobs
- View Worker Applications
- Accept or Reject Applications
- Track Application Statistics

### 🎨 UI Features
- Responsive Design
- Custom Notifications
- Custom Confirmation Modals
- Dashboard Navigation
- Form Validation

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/manjunath-madar/WorkConnect.git
```

2. Open the project folder in VS Code.

3. Open `index.html` using Live Server.

4. Register as a Worker or Employer.

5. Log in and explore the platform.

## 💾 Data Storage

Currently, WorkConnect uses browser LocalStorage to store user information, job postings, applications, and notifications.

A backend and database integration can be added in future development.
